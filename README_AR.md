# LYMELVA — Luxury Lymphedema Clinic Portfolio

**الإصدار:** v1.0 — نموذج تطوير فعلي، غير منشور، وليس نظام حجز إنتاجيًا.

موقع مستقل جديد 100% للعيادة، تم بناؤه على ألوان وشعار دليل LYMELVA التجريبي. الاسم **غير معتمد قانونيًا** حتى الآن، ويمكن تغيير النصوص والشعار لاحقًا.

## تشغيل الموقع على الجهاز

لا يحتاج اشتراكات أو API keys أو npm أو مكتبات خارجية. افتح Terminal أو PowerShell في فولدر الموقع:

```powershell
python -m http.server 8000
```

ثم افتح `http://localhost:8000` في المتصفح. لو Python مش عندك، يمكنك تشغيله باستخدام أي Static Web Server أو رفع المجلد كما هو على Vercel/Netlify/Cloudflare Pages.

## الهيكل

- `index.html` — هيكل الموقع والأقسام والـ SEO الأولي.
- `styles.css` — الهوية، Responsive، الثيمين (شمس/قمر)، الحركة ومراعاة Accessibility.
- `app.js` — عربي/إنجليزي، التفاعل، الخدمات، المحتوى، الفلاتر، FAQ، الدليل التعليمي، ونموذج الطلب المحلي.
- `assets/` — نفس شعار الهوية البصرية الأصلي + Brand Board.
- `guides/` — 3 ملفات PDF تثقيفية بالعربي والإنجليزي + دليل الهوية الأصلي.
- `docs/` — توثيق وتقرير الميزات والاختبارات ولقطات معاينة.
- `vercel.json` و`_headers` — إعدادات حماية متوافقة مع الاستضافة الثابتة.
- `robots.txt` و`meta robots=noindex` — يمنع فهرسة الهوية المؤقتة قبل الاعتماد.

## الميزات المنفّذة

- مدخل سينمائي يظهر عند كل تحديث، مع تخطٍ فوري وتقليل حركة حسب إعداد الجهاز.
- واجهة افتتاحية مصممة بأصل SVG متحرك فريد من نوعه؛ ليست صورة مسروقة ولا نموذج مرضى وهمي.
- تصميم Arabic RTL / English LTR مع تذكر اللغة عبر LocalStorage.
- وضع ليلي/نهاري كامل، زر شمسي/قمري متحرك، مع تذكر الاختيار.
- Header متجاوب مع التمرير، مؤشرات القائمة، Mobile menu مع Escape وFocus trap.
- خدمات تفاعلية (6 عناصر)، مع Dialog accessible وإغلاق Escape/backdrop.
- رحلة رعاية تفاعلية (4 خطوات)، ومكتبة معرفة بفلاتر (6 مقالات تعليمية)، FAQ تفاعلي.
- Guided Care Explorer: دليل إرشادي مبني على قواعد عامة، **غير تشخيصي وليس AI حقيقيًا**، ولا يجمع بيانات حساسة.
- 3 PDFs تعليمية أصلية قابلة للتحميل.
- نموذج ملخص استفسار محلي، مع Validation وCopy/Download من غير إرسال تلقائي.
- CTA عائم يختفي عند قسم التواصل حتى لا يغطي النموذج.
- SEO title/description/OG، structured data باسم مؤقت، مصادر NHS/Expert Consensus.
- Responsive للموبايل والتابلت والديسكتوب، مع دعم Reduced Motion والتركيز بالكيبورد.
- موقع Privacy-first: لا كوكيز، لا Tracker، لا Analytics، لا APIs أو خدمات مدفوعة.

## الحدود المهمة قبل النشر

1. **اسم العيادة:** LYMELVA مجرد اسم Branding مبدئي، ويحتاج موافقة المالك وفحص علامة تجارية.
2. **الحجز والتواصل:** لا يتم إرسال نموذج الطلب إلى خدمة بريد أو WhatsApp ولا يتم حجز مواعيد فعلًا. لا يوجد رقم أو عنوان رسمي مؤكد للعيادة؛ لا تضف أرقام ELHADY Works كأنها رقم العيادة.
3. **الصور والأعمال:** لا توجد شهادات/نتائج علاجية أو مرضى أو أعداد حالات مختلقة. يُنصح بإضافة صور أصلية للعيادة بموافقة أصحابها بعد الاعتماد.
4. **الترخيص الطبي/القانوني:** راجع محتوى الخدمات والمتطلبات التنظيمية المحلية والخصوصية قبل نشر الموقع لجمهور المرضى.
5. **الفهرسة:** `noindex` و`Disallow: /` لحين تغيير الاسم وبيانات الاتصال واعتماد المحتوى؛ يجب تحديثهم للإطلاق.
6. **النشر:** هذا تسليم كود مستقل، **توجد نسخة مستقلة على GitHub بمستودع clinic-portfolio، لكنها ليست نقلًا مطابقًا لحزمة الأصول الكاملة الموجودة في هذا ZIP، ولم يتم النشر على Vercel؛ مستودعات V.East وELHADY Works لم تُعدّل**.
7. **تجارب المتصفح:** الاختبارات شملت الواجهة عبر Chromium في بيئة اختبار مدمجة؛ لم يتم اختبار أصل منشور مباشر أو جهاز موبايل حقيقي.
