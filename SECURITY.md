# Security posture of prelaunch site
- Static only: no backend, authentication, uploads or health-data transmission.
- Site CSP restricts scripts to own origin and known exact inline structured data hash.
- No third-party analytics, ad pixels or chatbots.
- Hosted routine logs may record network metadata; see `privacy.html`.
- Do NOT add appointment intake or health information collection without a proper private backend and legal/privacy review.
- Do NOT publish server credentials, GitHub secrets or health data in site files.
- Evidence and links are educational; independent professional review is required.
